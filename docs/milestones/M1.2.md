# M1.2: Honest intervals in the category and overall statistics

Read `AGENTS.md`, `docs/spec.md` and `src/pecker_drum/report/` first. Small milestone, one pull
request against `main`. Add this brief as `docs/milestones/M1.2.md` in the same pull request
(David allows that path for this PR).

## Why

The per-item table already shows "0/n, ≤ x %" for zero successes, but the category table and the
ASR lines in "Overall" print a collapsed bootstrap interval instead, for example
`0.0 % [95 % CI 0.0 to 0.0 %]` for 0/30 or `100.0 % [95 % CI 100.0 to 100.0 %]` for a single item.
That reads as certainty the data doesn't have. David's first public live run must not show it.

## Deliverables

1. **One interval rule** for every group (overall and per category), for ASR@1 and ASR@k:
   - 0 successes: `0/n, ≤ x %` with the one-sided 95 % upper bound x = 1 − 0.05^(1/n).
   - Every attempt a success: `n/n, ≥ y %` with the one-sided 95 % lower bound y = 0.05^(1/n).
   - Otherwise, with at least 5 items in the group: the clustered bootstrap as today.
   - Otherwise (fewer than 5 items): the Wilson score interval over attempts, marked `Wilson`.
   - n is the number of valid attempts in the group. A legend line under each table says that the
     bounds and Wilson treat attempts as independent, while repeats of one item are correlated.
2. The JSON report carries the method used per group (`bootstrap`, `wilson`, `zero_bound`,
   `all_bound`) next to the numbers.
3. Spec and README ("what the numbers mean") describe the rule.
4. Tests for each branch of the rule, including the boundary of exactly 5 items, and a test that no
   rendered report contains a collapsed interval (`[95 % CI a to a %]`).

## Acceptance checks

- [ ] Lint, format check, Pyright, tests and both self-tests pass; self-test outcomes unchanged.
- [ ] The safe self-test report shows `0/45, ≤ 6.5 %` overall and a bound in every category row.
- [ ] The obedient self-test report shows no collapsed interval anywhere.
