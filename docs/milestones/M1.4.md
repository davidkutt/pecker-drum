# M1.4: Live-run settings from a `.env` file

Read `AGENTS.md`, `docs/spec.md`, `README.md` and `src/pecker_drum/cli.py` first. Small milestone,
one pull request against `main`, on a new branch from `main`. Add this brief as
`docs/milestones/M1.4.md` in the same pull request (David allows that path for this PR).

## Why

David wants to keep the OpenRouter key and his default live model in a local `.env` instead of
typing them for every run. Two constraints: the key must never leak into anything the harness
writes, and no environment value may turn a run into a live run on its own. Agents are blocked from
live runs by a gate that matches `--model openrouter` on the command line; that must stay effective.

## Deliverables

1. **Load `.env`** from the working directory at CLI start, if it exists. Values already set in the
   environment win over the file. Use `python-dotenv` (BSD-3-Clause, list it in
   `docs/dependencies.md`) or a minimal parser of your own; no other new dependency.
2. **Variables:** `OPENROUTER_API_KEY` (as today) and `DRUM_OPENROUTER_MODEL`.
3. **`--model openrouter`** without an id uses `DRUM_OPENROUTER_MODEL`; exit code 2 with a clear
   message if it is unset. `--model openrouter:<id>` keeps working and wins over the variable.
   `--model` stays required: no variable selects a live model unless the command line says
   `--model openrouter…`.
4. **`.env.example`** (committed): both variable names with empty values and one comment line each.
   `.gitignore` already ignores `.env` and `.env.*`; add `!.env.example` so the example is tracked,
   and check that `.env` itself stays ignored.
5. **No leaks:** a test with a recognisable fake key proves the key appears in no log line, report,
   checkpoint, run id or error message. The missing-key message names `.env` as an option.
6. **Docs:** README live-run section with the `.env` variant (create it from the example, restrict it
   with `chmod 600 .env`, run with `--model openrouter`), keeping the existing `read -s` variant.
   Commands in bash and fish as `AGENTS.md` requires. Spec note on the precedence rules.
